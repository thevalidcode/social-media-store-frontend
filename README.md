# Valid Panel -- Social Media Store 🚀

## Overview

A comprehensive, enterprise-grade Social Media Marketing (SMM) frontend platform built with **TypeScript** and **Next.js 15**. This project provides a robust interface for users to purchase social media services and for administrators to manage the entire ecosystem, including orders, service providers, and financial configurations.

## Features

- **Dual Dashboard Architecture**: Dedicated, high-performance interfaces for both clients and administrators.
- **Dynamic Theme Engine**: Real-time theme switching with persistent storage, allowing store owners to customize branding via CSS variables.
- **Multi-Currency System**: Integrated currency conversion logic using real-time rates and decimal precision for accurate financial transactions.
- **Advanced Order Management**: Supports bulk ordering, drip-feed configurations, and real-time order status synchronization.
- **Administrative Suite**: Full-featured control panel for managing users, support tickets, service providers (API integrations), and content (Blogs/FAQs).
- **Automated Service Sync**: Logic for importing and synchronizing services from external SMM providers via API keys.

## Getting Started

### Installation

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/thevalidcode/social-media-store-frontend.git
   ```
2. **Navigate to Directory**:
   ```bash
   cd social-media-store-frontend
   ```
3. **Install Dependencies**:
   ```bash
   npm install
   ```
4. **Run Development Server**:
   ```bash
   npm run dev
   ```

### Environment Variables

Create a `.env.local` file in the root directory and include the following:

```env
NEXT_PUBLIC_API_URL=http://localhost:6060/api/v1
NEXT_PUBLIC_DOMAIN=yourdomain.com
```

## Technologies Used

| Technology         | Purpose                                                       |
| :----------------- | :------------------------------------------------------------ |
| **Next.js 15**     | Core framework for SSR, routing, and performance optimization |
| **TypeScript**     | Static typing for enterprise-level code reliability           |
| **TanStack Query** | Server-state management and synchronization with the backend  |
| **Tailwind CSS**   | Utility-first styling with high-performance CSS delivery      |
| **Shadcn UI**      | High-quality, accessible component library based on Radix UI  |
| **Framer Motion**  | Advanced animation engine for smooth UI transitions           |
| **Axios**          | Promise-based HTTP client for robust API interactions         |
| **Decimal.js**     | Handling precision-critical financial calculations            |
